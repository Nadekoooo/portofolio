Kost dekat UI Depok Murah 

Banyak di antara kita yang belum tahu bahwa Universitas Indonesia (UI) merupakan universitas pertama kali yang ada di Indonesia. Kali ini, Mami akan menceritakan universitas yang berlokasi di Depok ini.

UI memiliki dua kampus yang letaknya berlainan tempat. Kampus utamanya berada di Depok, Jawa Barat berbatasan dengan Jakarta Selatan. Sementara, kampus duanya berada di Salemba, Jakarta Pusat.

Kampus UI menjadi salah satu universitas terkemuka di Indonesia. Banyak lulusannya yang akhirnya menjadi tokoh berpengaruh di Indonesia. Nah, oleh karenanya tak heran jika UI banyak diserbu oleh calon mahasiswa dari berbagai daerah di Indonesia.

Mereka yang berasal dari luar Depok tentunya membutuhkan kost untuk tinggal sementara. Akhirnya banyak warga sekitar yang membuka tempat kost dekat UI Depok.

Yang Perlu kalian Tahu Sebelum Kost di Dekat UI Depok

Jika Anda ingin kuliah dan kost di Depok, ada baiknya Anda mempersiapkan diri, baik secara fisik maupun mental untuk kost di Depok. Berikut hal-hal yang harus Anda ketahui sebelum kost di dekat UI Depok.

  • Berbeda dengan daerah kawasan kampus lainnya yang menggunakan bahasa daerah, khusus di Depok Anda harus siap dengan bahasa ‘gaul’. Percakapan sehari-hari di sini identik dengan percakapan anak muda metropolitan. Jika Anda datang dari daerah, Anda harus siap untuk beradaptasi dengan kondisi ini.
  • Sebagai kota satelit, Depok juga identik dengan kemacetan. Anda harus memahami betul jalan alternatif di sini untuk menghindari kemacetan.
  • Depok menjadi salah satu kota di Jawa Barat dengan biaya hidup yang tinggi. Jika ingin tinggal dan kuliah di UI Depok, ada baiknya Anda mempersiapkan rencana anggaran setiap bulannya agar pengeluaran tidak membengkak.
Jika Anda tertarik untuk mengetahui lebih banyak tentang kost di Depok UI atau kost di Depok murah, silakan kunjungi website Mamikos dan unduh aplikasinya.

Tempat Menarik di Sekitar UI Depok

Jika Anda tertarik untuk menjadi mahasiswa UI dan cari kost di Depok dekat UI, akan lebih baik jika Anda mengetahui tempat-tempat menarik berikut. Simak ulasan Mami tentang tempat menarik di seputar UI berikut ini.

  • Mahasiswa tak lepas dari tugas dan laporan. Terkadang, laporan atau tugas membutuhkan referensi yang harus didapatkan dari buku. Silakan datang ke perpustakaan UI. Di sini Anda dapat menemukan buku-buku yang mungkin tidak dapat Anda dapatkan di perpustakaan lain. Hal ini dikarenakan perpustakaan UI merupakan perpustakaan terbesar di Asia Tenggara.

  • Ada sebuah warteg terkenal yang tidak bisa Anda lewatkan jika Anda tinggal di sekitar UI, ialah warteg Sasari sebutan untuk warteg yang buka 24 jam ini. Letaknya di belakang rel kereta sebelah Fakultas Hukum (Barel).

  • Satu tempat yang sering dijadikan tempat nongkrong anak UI adalah Cakor alias Cafe Korea. Letak Cakor ini di perpustakaan pusat UI. Banyak mahasiswa UI yang menghabiskan waktu untuk mencari koneksi wifi dan mengerjakan tugas di sini.

Nah untuk masalah mencari kost di dekat UI Depok , ini gampang-gampang susah, letaknya yang dekat dengan Ibu Kota membuat kost di sini agaknya lebih mahal dibanding daerah lainnya.

Jika Anda tertarik untuk kost di depok dekat UI atau kost dekat Gunadarma Margonda atau kost pocin depok murah, ada baiknya Anda unduh aplikasi pencari kost, mamikos untuk membantu Anda menemukan kost yang ideal atau jika anda adalah pemilik rumah kost, silahkan promosikan usaha kost anda disini.
